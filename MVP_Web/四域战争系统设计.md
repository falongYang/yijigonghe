# 《蚁纪·共时》四域战争系统 — 设计说明（v2.1）

> 在 RTS 框架上扩展的五大系统：资源 / 武器 / 能力 / 成长 / 四域环境。
> 代码位置：`MVP_Web/js/{rts,sim,ants,world,ui,main}.{js}`，入口 `index.html`。

## 1. 资源系统（三资源经济）
- **生物质(生)**：主经济。工蚁在陆地/水面/空中资源点采集叶片·藻·花粉，运回巢室。
- **矿物(矿)**：地下掘蚁在「地下矿脉」节点采掘。解锁空中/地下巢室与重装、高级兵种。
- **信息素(素)**：蚁后巢（1.2/s）与史官堂（3.0/s）自动生成，施放主动能力消耗。
- 掠夺：击杀正在搬运的敌方工蚁可截获其携带资源；拆毁敌方建筑获得生物质赏金。
- 实现：`sim.res{P:{bio,min,ph}}`、`canAfford/spend/gainRes`、`_initNodes`（10 个四域资源点）。

## 2. 武器系统（伤害类型 × 护甲克制）
- 6 种伤害类型：`撕咬 bite / 酸液 acid / 毒针 sting / 穿刺 pierce / 轰炸 bomb / 灵能 psi`。
- 5 种护甲：`软 soft / 几丁 chitin / 重甲 armored / 飞行 flying / 甲壳 shell`。
- 克制表 `ARMOR_MULT`（如酸液克几丁 1.3×、穿刺克重甲 1.3×、毒针克软甲 1.3×）。
- 伤害结算：`dmg × 信息素光环 × 目标减伤 buff × 克制倍率`（`sim._dealDamage`）。
- 武器弹道特效：酸弹、毒针、穿刺光束、轰炸落弹、近战火花等（`world.addEffect`）。

## 3. 能力系统（信息素驱动的主动技能）
10 种能力，统一 `{cost 信息素, cd 冷却, desc}`，落点施放：
| 键 | 能力 | 效果 |
|---|---|---|
| Q | 兵种能力 | 兵蚁狂暴/酸蚁酸池/桨卫涡卷/飞蚁俯冲/掘蚁钻地… |
| E | 信息素号令 | 全军伤害 +20%（8s） |
| R | 纪元共鸣 | 全军伤害 +10%（10s，纪元科技爆发） |
| — | 酸液覆盖/毒雾/滑翔轰炸/俯冲轰炸/钻地突袭 | 范围持续/爆发伤害（hazard） |
- 实现：`ABILITIES`、`castAbility(side,key,x,z)`、`_buffUnits/_addHazard/_dmgRadius`、`sim.cd` 冷却、`ui` 三能力按钮。

## 4. 成长系统（经验 / 等级 / 进化）
- 单位作战获得经验（`_gainXp`），每级 +8% 生命与伤害（`LEVEL_HP/LEVEL_DMG`），满 5 级。
- **进化路线**（达条件 `Lv5 + 纪元2 + 矿60` 后可进化，按 T）：
  - 兵蚁(s1) → 巨颚卫(s3)；桨卫(sA) → 潜袭蚁(sB)；飞蚁(aA) → 滑翔蚁(aB)；隧道蚁(uA) → 钻地刺蚁(uB)。
  - 进化重算属性并保留等级，外观/武器/护甲随之改变。
- 纪元研究（史官堂）推进 0→5，全族群属性 +7%/纪元，解锁更高级兵种。
- 实现：`XP_PER_LEVEL`、`_gainXp`、`canEvolve/evolve`、AI 自动进化。

## 5. 四域环境（陆 / 海 / 空 / 地下）
- 各域专属资源点与巢室，对应兵种只能在己方域巢生产：
  - **陆**（默认）：工蚁 / 兵蚁 / 酸蚁 / 巨颚卫。
  - **海**（水栖巢室）：桨蚁(采藻) / 桨卫 / 潜袭蚁。
  - **空**（空中蜂巢）：浮蚁(空采) / 飞蚁 / 滑翔蚁——飞行悬空越障、可轰炸陆海。
  - **地**（地下菌核）：掘蚁(采矿) / 隧道蚁 / 钻地刺蚁——**潜行时不可被锁定**，破土突袭。
- 环境差异：`underground` 单位 `burrowed` 时提速且半透不可锁；`air` 单位渲染悬空；域巢与资源点各带主题色。
- 13 个兵种 × 6 品种 × 4 域共 120 种几何（`buildAntGeometry(sp,caste,carry,domain)`）。

## 7. 操作
- **选择与指令**：左键点选 / Shift 框选 / 双击全选同兵种；右键移动或攻击（多选自动按方阵散开）；`Shift + 右键` 追加路径点，单位依次经过；`A` 攻击移动、`S` 停止（清空路径点）、`H` 驻守。选中单位显示地面指令线与终点标记。
- **能力**：`Q` 兵种能力、`E` 信息素号令、`R` 纪元共鸣 —— 先选能力再左键点地面选落点，右键 / `Esc` 取消；`T` 进化单个达标单位。
- **相机**：中键旋转、滚轮缩放、`方向键 / W·D` 平移、鼠标贴边自动平移、点小地图跳转；`空格` 回到己方巢区、`F` 跟随选中单位（手动平移即退出）。`A / S` 专用于攻击移动 / 停止，不再与相机平移冲突。
- **编队与流程**：`Ctrl/⌘ + 数字` 保存编队、数字键选中；`P` 暂停菜单（含战局统计与偏好设置）；右上可全屏、保存战场截图、静音。
- **建造与生产**：建造按钮进入放置态，鼠标移动实时显示占地幽灵盘与合法性原因（绿可建 / 红不可建，校验与 `startBuild` 共用 `checkBuild`，并含深水 / 陡坡判定）；选中生产建筑后右键地面设集结点；生产队列显示进度并可点 `×` 取消退还资源。
- **工蚁调度与维修**：`I` 选中闲置工蚁（无闲置则全选工蚁），`C` 让选中工蚁清掉手动命令就近续采；资源点采空后按 `regen` 缓慢回满。选中受损己方巢室点「派工蚁维修」，或选中工蚁后右键该建筑，工蚁会耗矿修复、修满自动回归采集。
- **地图与侦察**：开局弹出战场简报卡（地貌 / 战术提示 / 四域资源 / 地形构成），点资源栏地图名可重看；`Alt + 左键` 在地面放置战术标记（脉冲环 + 光柱，小地图同步，3.2s 消失）；鼠标所指地形在图例条显示名称与效果。
- 摧毁敌方蚁后巢即胜。

## 7.1 战局统计
`sim.stats` 按阵营记录击杀 / 损失 / 建造 / 累计采集 / 能力施放 / 进化 / 掠夺量 / 维修耐久 / 信息素井产素，暂停菜单与结局面板展示，用于复盘与平衡调参。

## 7.2 信息呈现与反馈（第 6 轮细节）
- **单体详情卡**：选中单个单位（含敌方）显示 HP、等级与经验进度、攻击 / 射程 / 攻速 / 移速、护甲、携带、武器与伤害类型、最优 / 最差克制倍率、当前状态、兵种能力；多选仍用兵种计数视图。
- **指令反馈环**：右键移动（青）、攻击 / 攻击移动（橙）、追加路径点（金）、设集结点（蓝）在落点生成地面脉冲环；配合已有指令路径线形成完整反馈。
- **敌方来袭警报**：AI 发起进攻波次时发出 `aiAttack` 事件，顶部警告条 + 小地图红闪 + 战斗日志 + 音效，8s 冷却防刷屏。
- **纪元环境联动**：纪元推进时 `world.setEra` 在 1.8s 内平滑过渡太阳光 / 半球光 / 背景 / 雾 / 天空色；开局在 `loadMap` 之后立即到位（此前 setEra 只在开局调用且被 loadMap 覆盖，纪元推进从未改变场景）。
- **战斗音效补全**：`build / research / evolve / rally / produce / dmg / death / aiAttack` 事件接到已定义却未使用的 WebAudio 音效，命中与死亡按 150ms / 320ms 节流；新增音量控制。
- **偏好设置（暂停菜单内，localStorage 持久化）**：音量、边缘滚屏、浮动伤害数字、帧率指示、画质自动调档 / 手动三档。`world.setQualityMode` 支持手动锁定档位。

## 7.3 地图细节（第 7 轮）
- **主题元数据**：`MAP_THEMES` 六章各补 `tag / desc / brief`，供开局简报卡、地图名 tooltip 与小地图图例使用；遭遇战沿用第 0 章配置。
- **地形结构**：按章节配置生成「巢区 → 各资源点」的贴地弯曲蚁道（带状几何，顶点高度复用 `_groundY` 与地形起伏一致）、双方阵营色领地双环、地图外圈 72 块低矮边界岩脊。
- **水域**：主水面颜色随地图主题混合；外缘浅滩环 + 两道由内向外扩散淡出的同心波纹（`_updateAmbient` 驱动）。
- **资源点造型**：按四域区分 —— 陆=三簇菌伞、海=浮叶+叶脉+花苞、空=悬浮孢子球+光环、地下=三根矿晶柱；储量比驱动整体缩放与自发光脉冲，`n.owner / n.glow` 驱动的归属环按采集方染色（采集后约 4.5s 衰减）。
- **战术小地图**：换图时缓存一张地形明暗底图（`noise2` 同款公式 + 边缘暗角 + 坐标网格 + 水域 + 巢区环），每帧叠加危险区、按域着色且随储量变化的资源点、采集归属描边、集结点、双方建筑与单位、白框相机视野、黄色战术标记。
- **战术标记**：`Alt + 左键` → `world.addPing` 生成地面脉冲环 + 光柱，小地图同步绘制，3.2s 后回收；同屏最多 6 个，换局清空。暂停时冻结。

## 7.4 战术地形 / 信息素井 / 维修（第 8 轮）
- **地形唯一真源**：`rts.js` 导出 `terrainNoise / terrainHeight`，`world.js` 的地面顶点与贴地装饰、`ui.js` 的小地图明暗底图、`sim.js` 的坡度判定全部共用同一公式，杜绝「看起来是坡、逻辑上是平地」。
- **战术地形**：`mapZones(cfg)` 按章节名做确定性哈希，生成 2 高台 + 2 泥沼 + 每片水域对应的浅滩（旋转椭圆，避开双方巢区与深水）。高台让远程单位射程 +18%；泥沼使地面移速 −22%；浅滩使陆地移速 −28%（水栖兵种在水中 +10%，空域 / 地下单位免疫地面减速）。`sim.zoneAt` 取归一化距离最小的区。
- **地形可视**：贴地色斑网格（顶点跟随起伏）、发光描边呼吸、高台岩标 / 泥沼气泡、中文地貌标签；小地图底图叠半透明色斑；单体详情卡显示所处地形与免疫说明；鼠标所指地形显示在小地图图例条；地图简报卡统计地形构成。
- **中立信息素井**：`mapWells(cfg)` 在避开深水与巢区的位置放 1–2 口井，并对与资源点重合的井做确定性 4 向错位（避开水面 / 边界 / 巢区），保证井需要主动派兵去争、而不是被采集中枢的工蚁顺手占领。圈内兵力多的一方以 `WELL.capture` 推进占领进度（人多更快，双方同场则停滞），进度满 ±1 才易主；归属方每秒 +1.5 信息素，计入 `stats.wellPh`。3D 端为占领圈 + 悬浮晶体 + 旋转环 + 光柱，按归属染色；资源栏 chip 与小地图动态显示归属与进度弧；占领 / 易主发日志、toast 与音效。
- **工蚁维修**：`sim.assignRepair / commandRepair / _repair / _endRepair`。最多 2 只最近工蚁前往受损巢室，按 `REPAIR_RATE=11 HP/s` 恢复并消耗 `0.25 矿/HP`；矿不足、建筑损毁或修满即结束并回归采集。维修期间每 0.45s 生成金色反馈环，建筑面板显示维修中工蚁数，暂停 / 结局统计新增维修耐久。
- **建造地形合法性**：`checkBuild` 增加坡度 >4.2 与深水（水心 `r*0.55` 内，巢区 18 半径豁免）判定，放置预览与实建共用同一结果，并在可建原因里附带地貌名。
- **统计 / 文案**：暂停与结局面板新增「维修耐久 / 井产信息素」；帮助页新增「战术地形与信息素井」「工蚁调度与维修」两节，首次引导同步；`ring` 特效补上 material 释放。

> 本节为本地构建的一部分（第 8 轮）；第 8/9/10 轮与首页修复均累计在本地 `MVP_Web/`，整包一并发布。

## 7.5 昼夜循环 / 受击反馈 / 纪元面板（第 10 轮）
- **昼夜循环（地图氛围）**：`world._tickDayNight` 以约 200s 为周期平滑推移太阳光强度与色温、半球光、背景与天空色（入夜趋近深蓝夜空），叠加在纪元主题色之上；每场战斗在 `loadMap` 时从清晨重置。资源栏新增时段 chip（🌑深夜 / 🌅黎明 / ☀白昼 / 🌇黄昏 / 🌙夜晚），夜幕经 `#night-veil` 径向暗化增强氛围。
- **真实受击闪白（战斗清晰度）**：单位受击时 `u.flash` 触发本体白色自发光（`emissive` 强度随 0.16s 衰减），替代原先仅缩放的提示；每个单位独立克隆材质以支持逐单位自发光，地下掘蚁潜行半透与敌方性格辉光仍保留。
- **纪元演进面板（六纪元主题）**：资源栏「纪元谱」按钮或 `Y` 键打开，展示六纪元轨道（当前高亮、已过变灰）、本纪元可生产作战兵种（按陆/海/空/地分组）、场上满足进化条件的己方单位数；呼应核心主题并辅助策略规划。
- **帮助同步**：帮助页新增昼夜循环与纪元谱（Y）说明。

## 9. 已知限制（MVP 范围）
单战场；已支持移动端触控（仍需持续真机验证），HTTPS 需单独部署配置；帧率依机器性能，已加入按帧率自动调节像素比 / 浮尘 / 阴影的画质降档；数值为可玩调参非最终平衡；跨域采用「潜行 + 飞行」机制而非硬性克制以保可玩性。音效为 WebAudio 程序化合成，无外部音频资源。


## 10. 移动与寻路（2026-11-14）

新增 `navigation.js`，地面单位使用可见图 A* 绕开建筑与可破坏障碍；飞行及潜行单位越障。施工和障碍移除自动刷新路线；实体内部目标投影到占地外缘；位移限幅避免到点越过。详细规则、边界和验证见仓库 `docs/开发路线与验收.md`。完整回归入口为 `npm test`。


## 11. 战斗与战术体验（2026-11-14 第二轮）

普攻按起手—发射/接触—命中执行；攻击移动交战后续行，H 驻守与眩晕行动限制修复，狂暴/号令增伤实际结算。按 L 打开全图，支持定位、下令、侦察记忆和战场纪事；结算显示实际胜因与高光。六足/触角通过共享几何的铰点属性与顶点动画驱动，并与阴影同步；单位、建筑、落点和轨迹统一地形高度。具体规则与边界见 `docs/战斗与战术体验升级.md`。
