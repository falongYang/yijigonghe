玩法说明

资源系统

生物质(生)：主经济，工蚁在资源点采集后运回巢。矿物(矿)：地下掘蚁采掘，解锁空中/地下与重装兵种。信息素(素)：蚁后巢与史官堂自动生成，施放主动能力消耗。

四域环境

陆/海/空/地下。各域有专属资源与巢室：水栖巢室→海兵、空中蜂巢→空兵、地下菌核→地兵。飞行蚁悬空越障、掘蚁潜行时不可被锁定（破土突袭）。

武器与克制

伤害类型（撕咬/酸液/毒针/穿刺/轰炸/灵能）对各护甲（软/几丁/重甲/飞行/甲壳）有不同倍率。按兵种合理组军。

能力与成长

选兵后按 Q 放兵种能力；E 号令、R 纪元共鸣（耗信息素）。单位作战获得经验，升级提升属性；达条件可按 T 进化（如兵蚁→巨颚卫）。累计击杀还会点亮老兵阶梯（老兵 / 精锐 / 王牌）：脚下光晕环与选中卡的战绩进度条会随之变色，纯荣誉外观、不改变任何属性。受击时单位会沿来袭方向后仰、按伤害类型闪出不同颜色（撕咬暖黄 / 酸液翠绿 / 轰炸橙红 / 灵能紫），重击附带短促顿帧与镜头冲击；下令后脚下会扩散一圈指令反馈环，密集队形会轻微收拢以便分辨个体。不同域与兵种的转身速率、步频起伏、起手蓄力与后坐回弹各不相同（飞行蚁转身最灵动、水栖更沉稳、远程后坐更明显），这些手感差异只影响动作表现，不改动任何战斗数值。

操作

左键点选 / Shift 框选；双击己方单位可全选同兵种；右键移动或攻击（多选自动按阵型散开）；Shift + 右键 追加路径点，单位依次经过；A 攻击移动、S 停止（并清空路径点）、H 驻守。G 进入巡逻布点：左键依次落下巡逻点、右键或回车确认、Esc 取消，选中单位会循环巡走这些点；V 循环切换阵型（散开→线→纵列→楔形→自动）。选中单位会显示地面指令线与终点标记。

相机：按住左键或右键在地图上拖动即可跟手平移视角（单击仍照常点选 / 下令，拖动不会误发指令）；中键拖动旋转、滚轮缩放，另有 方向键 / W·D 平移与鼠标贴边自动平移（可在设置关闭）；点击或拖动小地图跳转；空格 回到己方巢区、F 跟随选中单位（手动平移即退出）。A / S 专用于攻击移动 / 停止，不再平移镜头。

触屏 / 平板操作

在触屏设备上，轻点画面点选单位（连续轻点两次同样全选同兵种），长按约半秒即等同右键下令（移动 / 攻击 / 设集结点，并附带轻微震动反馈）；单指拖动跟手平移镜头，双指捏合平滑缩放（与滚轮共用阻尼通道，连续手势不会让镜头漂移）、双指同向拖动平移、双指旋转调整视角。点按或拖动小地图同样可跳转镜头，开始页的蚁种 / 章节卡片可直接左右滑动切换。暂停、引导或显卡恢复期间手势自动停用，避免误操作；按 Esc 会先收起帮助与纪元谱，再依次取消巡逻、瞄准或暂停。

Ctrl/⌘ + 数字 编队、数字键快速选中；P 暂停菜单内有音量、边缘滚屏、伤害数字、帧率、画质档位、战场提示（镜头冲击 / 字幕 / 加权音效）与默认情报图层等偏好设置（自动保存，可随时关掉镜头震动）；开始页的指挥官代号输入会实时显示字数与合法性校验、按 Enter 保存 / Esc 撤销，其他标签页修改档案时本页会自动同步；档案卡可导出 / 导入 JSON 备份用于换机迁移（导入逐字段校验，损坏或无关文件会被拒绝）、展开状态会记住，战绩区还显示最近 8 局的胜负走势条；右上可全屏与保存战场截图，画质默认按帧率自动调节（档位同时限制渲染像素比、草砾密度与远景装饰，拉远镜头会自动隐去细碎装饰但保留大地标，切回精细档可完全恢复）。重大战斗事件（伏击、据点失守、地脉共振等）会按其强度触发短促的镜头冲击与推拉、底部战场字幕与加权音效；镜头推拉只作用于当前画面、会自动回弹，不会改变你设定的缩放位置。受损建筑会随耐久下降逐步熏黑、浮现裂痕与余烬脉冲、烟尘变浓，资源点则按储量阶段调整辉光与脉冲节奏。窗口缩放、横竖屏切换或跨屏拖动时画面会即时重建绘图缓冲，HUD 会随窗口大小自动收敛，窄屏下侧栏限高可滚动；系统开启「减少动态效果」后会跳过入场俯冲运镜与界面装饰动画；显卡上下文意外中断时战局自动冻结并给出提示，恢复后从原处继续、不补算中断时间。单位会按待命 / 作业 / 搬运 / 行军 / 突进 / 交战 / 游斗 / 据守 / 巡逻等姿态平滑改变前倾幅度、重心与步幅，只影响动作表现；画面中心附近正在大规模交战时，镜头会自动极轻微推近、环境底噪随之压低，让战斗音效更清楚。小地图上方的阵营态势条实时对比双方存活数与平均聚簇密度（窄屏自动隐藏）。

选中单个单位（含敌方）可查看完整属性、经验进度、武器克制与所处地形；右键指令会在落点显示反馈环。选建造巢室后移动鼠标会实时显示占地预览与可建原因（深水 / 陡坡不可建）。选中生产建筑后右键地面设集结点；生产队列可点 × 取消并退还资源。摧毁敌方蚁后巢即胜。任务目标会在左上「作战目标」条实时显示进度（存活倒计时 / 采集量 / 占井守时），精炼巢室与资源贸易状态也会在资源栏下方常驻提示。

地图与侦察

开局显示战场简报（地貌特征 / 战术提示 / 四域资源 / 地形构成），点击资源栏的地图名可随时重看。地面蚁道连接巢区与资源点，浅色圆环标出双方巢区，水域带浅滩与扩散波纹；资源点按陆 / 海 / 空 / 地下使用不同造型，被采集时归属环会染成采集方颜色。地面贴有战术坐标网格（每 20 单位细线、每 5 格主线、中轴基准线与边缘刻度，拉近镜头更清晰）；右下小地图显示主次网格与坐标刻度、地形明暗、水域、战术地形、资源储量、集结点与白框视野，交战处会亮起短寿红橙热点（克制 / 重创更亮）并留下阵亡消散圈，一眼可辨战场哪里在打；Alt + 左键 可在地面放置战术标记（地面脉冲环 + 小地图黄圈，约 3 秒消失）。鼠标所指的地貌名与效果会显示在图例条上。昼夜循环贯穿整局：天色、光照与夜幕会随战局缓慢推移（资源栏右侧显示当前时段），入夜视野与氛围更紧张；六章各有独立的昼夜周期与相位偏移（沃野晨光更早、泽国雾夜更频繁、虚空近乎恒夜），并按拂晓 / 正昼 / 黄昏 / 夜幕四相位平滑插值日月色与环境光，不会在切换瞬间跳变。战役天气会随战局按时间线转变（晴空 / 细雨 / 劲风 / 薄雾 / 风暴 / 共振），实时改变视野半径与远程命中，并在雾色与降水上直观呈现；左上天气条显示当前气象、视野 / 远程修正与下一次转变倒计时（遭遇战气象恒定）。各章还散落确定性地面装饰（草簇 / 石砾 / 菌菇 / 枯枝 / 水洼 / 孢子 / 残骸 / 晶簇），并各自带有飘散风向与辉光色调；战役中周期性触发场景异象（灰烬回潮、孢子潮汐等），顶部横幅会播报叙事文本与剩余时间，画面雾色随之轻微脉冲，纯氛围不影响任何结算。按 Y 打开纪元演进面板，查看六纪元进度、本纪元可生产兵种与场上进化潜力。按 M 或点击小地图下方「情报」按钮可开启情报图层：敌方单位按网格聚合成红色热区，静态危害 / 地脉共振 / 场景事件按类别配色与重要度标出，并列出中文图例；再按一次关闭，暂停时也可开启用于复盘。战斗结束的结算页会额外给出战场叙事战报（实战时长、交换比、峰值兵力、老兵晋升、精英击杀、气象转变等只读聚合数据）。

各章还按确定性布点散落大尺度地形地标（巨岩 / 枯桅 / 晶柱 / 石柱 / 碎石堆 / 盐柱 / 碑石），与近水、地图边缘、资源点周边的生态分区着色一起形成可辨识的地貌层次；平滑地表高程只影响地面与静态大件的明暗，不改变任何单位高度、坡度或判定。每片水域另有各自的水体色、波纹频率、潮汐周期与闪光强度，小地图静态底图会标出活动边界、地形危害与地标（与实时单位 / 建筑图层分开绘制）。

战术地形与信息素井

每章战场有高台（远程单位射程 +18%）、泥沼（地面移速 −22%）与浅滩（陆地移速 −28%，水栖兵种在水中略提速）；空域与地下单位免疫地面减速。地面有贴地色斑、发光描边与地貌标签，单体详情卡也会标出当前所处地形。信息素井是中立的争夺点：把单位驻在圈内即可推进占领进度（人多的一方更快，双方同时在场则停滞），占满后持续为该方产出信息素，资源栏与小地图实时显示归属。

工蚁调度与维修

I 选中全部闲置工蚁（无闲置时则全选工蚁），C 让选中工蚁就近返回资源点续采；资源点被采空后会缓慢再生，采集热度会在小地图与地面归属环上实时体现。巢室受损时，选中它点「派工蚁维修」，或选中工蚁后右键该建筑：工蚁会前往持续消耗矿物恢复耐久，修满后自动回归采集。
