# R4 第一章主动策略纯模拟探针

日期：2026-11-16。

## 结论

同一正常生产进攻策略，三档各10个固定种子：简单10胜、普通10胜、困难3胜7负。证实第一章存在使用实际采集、建造、生产与进攻规则的自然获胜路径；不代表浏览器主动游玩体验、触控板实机、总体平衡或完整游戏已经验收通过。

## 复现

仓库根目录运行 `bun probe-r4-active.mjs`，结果与 `R4-主动策略探针.json` 对照。随机数为LCG，种子20261116–20261125，每档相同种子。模拟步长0.05秒，最长600秒或自然终局，不把提前终局算作600秒样本。

第一章、SP01，保留默认资源、工蚁与采集、敌军和AI。开局在(10,35)建兵营；每秒检查队列，按2兵蚁/1酸蚁循环生产（正常科技/费用限制仍生效）；25秒后生物质超过500且兵营少于3座时尝试增建。每秒向已知地图目标坐标(0,-41.54)下攻击移动。没有注入资源、单位、伤害，没有修改AI或胜负判定，没有直接读取敌军位置进行微操；策略预先知道固定敌HQ坐标，不能据此证明侦察体验完整。

## 限制

这是每秒自动下令的纯模拟策略，不是人类实际操作。没有验证输入、镜头、UI理解成本、自然结算画面、重开、移动设备或物理触控板。一个品种、一章、一个主策略与10种子不能外推所有阵容或章节；困难胜率差异是本策略观察结果，不能称总体平衡通过。
