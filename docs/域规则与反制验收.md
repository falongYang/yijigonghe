# 域规则与反制验收

日期：2026-11-14。基线：33559db。默认不部署服务器。

## 规则

- 武器 `air: true` 是普攻对空的唯一真值：酸液、警戒酸弹、潜袭毒针、飞蚁、滑翔蚁；撕咬、巨颚、桨击、掘颚、钻地突刺不能对空。空域经济单位使用普通撕咬，因此也不能对空。
- `canAttack` 统一控制自动索敌、战术索敌、手动指令、起手和释放；弹体命中、普通攻击溅射再次校验。范围技能与环境危害保持独立规则，不把普通武器权限套到技能。
- 建成且存活的主巢中心半径 20、警戒塔中心半径 22 提供侦测；存活的非潜行单位在 4 距离嗅探，空军也可嗅探。双方对称。
- 地下潜行单位被侦测后 `revealed` 为真；离开侦测 1.5 模拟秒后撤销。表现层只读，不写回。攻击起手即浮出；现有手动移动、采集等浮出规则保留。
- 未揭示的敌方潜行单位不进入可见单位渲染；鼠标射线过滤隐藏祖先，避免点击隐藏模型。侦测不是额外的全图视野。
- 单位卡、建筑卡和帮助从武器/侦测数据派生标签；选中己方主巢或塔时显示随地形起伏的侦测圈，揭示单位有蓝色状态反馈。
- AI 仅在己方视野内观察到空军时补充已解锁的对空兵种，合计现役和排队，目标至少 3 个或现役战斗单位约三分之一。所有阵营均可用公共兵营的酸蚁和警戒塔，因此未额外增加主巢对空武器。

## 验证

- `npm test`：完整回归通过，新增 `test-domain-rules.mjs` 覆盖五类近战、四种对空单位、塔命中、三个侦测源、1.5 秒边界、失锁弹体、出手浮出、死亡/施工不侦测、数据派生帮助、隐藏拾取、AI 只对可见空军调整及三难度固定种子复现。
- `npm run test:soak`：六章 × 三档难度，18 组，50,947 tick，不变量全通过。
- `node probe-domain-pace.mjs`：与 33559db 的逻辑/数据模块 A/B，固定种子 4567，三难度前 60 秒，每 10 秒采样经济、纪元、单位位置/生命、建筑队列及 AI 状态，序列逐字一致。该结果不代表交战后的平衡不变。
- `npm run test:balance`：固定种子 20261114，40 秒受控交战，逐帧真实起手、弹体、侦测和单位决策；不执行宏观 AI 经济。各场四只攻击单位对四只防守单位，反制场另加一塔。
- Chrome 软件 WebGL 冒烟通过，运行时错误为零。覆盖 1440×960、844×390、开局/绕障/全图/结算、失焦释放输入、帮助内容、主巢侦测圈和酸蚁卡对空标签；已检查窄屏截图。浏览器依赖仅在临时目录安装。

## 交换探针实测

三档难度在这组隔离交战中结果相同；难度主要影响未运行的宏观 AI，不能把三行相同结果当作难度平衡证据。交换比为敌方损失数 / 我方损失数；零分母用空值，不伪造有限比率。

| 场景 | 我方损失 | 敌方单位损失 | 我方累计承伤 | 交换比 |
| --- | --- | --- | --- | --- |
| 4 飞蚁对 4 巨颚卫 | 0 | 4 | 0 | 无定义（零损失） |
| 4 飞蚁对 4 酸蚁加塔 | 4 | 0 | 507 | 0 |
| 4 隧道蚁对 4 巨颚卫加塔 | 4 | 0 | 699 | 0 |

纯空军对无法对空的近战无损是规则的预期结果；带反制的防线造成真实损失，验证反制存在。此处不等资源、不模拟技能、没有玩家微操，尚不能判断反制强度是否适合正式平衡。地下单位接敌会主动浮出，因此还以独立侦测断言证明塔可锁定尚在潜行的目标。
