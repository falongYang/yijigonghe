# R4 造价调整与潜行复核

基线 52c7562；本轮不部署。只调整 rts.js 中三种兵的生物质/矿物造价；不改伤害、对空白名单、侦测半径、指令或建造时间。

## 复现与局限

运行 `node probe-r4-budget.mjs --budget`。种子 20261114/20261115/20261116，easy/normal/hard 各三次，步长 0.05，90 模拟秒未结束标 timeout，未完成交战不能判通过。reset 后设种子、清空初始单位/建筑/障碍、禁用战术 AI。坐标、阵容、成本、损失、剩余数量及原始值在 JSON 和脚本内。成本为配置 bio+min；未模拟采集、矿物稀缺、前置建筑或生产时间，不能替代实战资源等价判断。

DeepSeek 附件没有提供探针源码、坐标和具体种子，因此本探针是独立复核，不能称与附件逐字同口径。使用 SP01 默认双方族群，不人为构造潜行移动状态。基线 C3 R=0，与附件 0.21 有差异；两者均不通过。这项方法差异保留为调查项。

塔造价190，占预算1000的19%。进攻阵容按固定类型序列循环补员，到下一单位会超1000时停止；防守阵容固定。双方实际花费并非严格相等，必须结合原始预算差额解读。难度在隔离交战中不代表战役 AI，九次一致不能增加实战置信度。
