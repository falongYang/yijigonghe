# 《蚁纪·共时》开发路线与验收

更新：2026-11-14。项目：yijigonghe。

## 当前基线

原生 ES Modules + Three.js 的单机 RTS，已有六品种、四域兵种、三资源经济、建造生产、升级进化、状态效果、战役与遭遇战、敌方 AI、地形与信息素井、动态天气与昼夜、触屏、空间音效及本地指挥官档案。档案是浏览器本地身份，不是联网账户；战绩备份不等于战局存档。

## 第一阶段：移动与可靠性（本轮交付）

- navigation.js 提供确定性的可见图 A*，按建筑半径（size / 2）和障碍半径外扩 0.65 的单位间距。
- 16 边外切轮廓保证相邻路径边不切入圆形占地；每段位移仍用实际圆形碰撞校验。
- 两阵营、陆地与水栖地面移动使用同一导航规则。飞行、正在潜行的地下单位直接越障；已浮出地面的地下单位遵守阻挡。
- 场景占地改变时自动使单位路线失效。静态边可见性跨单位复用；无路结果缓存，避免每帧重复搜索。
- 目标位于建筑/障碍内部时，改为接近可达外缘，不再要求进入实体中心。新建筑覆盖到单位时允许朝外脱离。
- 友军避让限制为横向分量，接近落点时减弱，避免挤压导致倒退。移动步长不超过剩余距离，避免大时间步越过目标。
- HUD 在中小窗口将资源栏与控制栏分行，窄屏横向滚动保留所有控制；气象、详情面板随之下移，修复顶部叠字和按钮遮挡。
- 浏览器实测发现背景远山伸入战场并大面积遮挡地面；已将完整山体移出战场，按天空之后、可玩场景之前绘制且不写深度，避免低视角遮挡单位。
- 保持采集、维修、攻击、巡逻、路径点、阵型命令和渲染事件接口不变。不引入新的四域通行或水域封锁规则。

### 验收

`npm test` 统一执行全部模块语法、导入审计、原有逻辑回归、第 14–33 批检查和新增寻路行为测试。

新增 29 项断言：单障碍绕行、逐段碰撞安全、确定性、缓存复用、障碍移除、重叠障碍、目标外缘、实体内脱离、封闭区域不可达、真实单位到达、大时间步停止、空中/潜行越障、建筑绕行、施工重新规划、维修完成、30 单位编队和不可达路线缓存。

真实 Chrome（软件 WebGL）验证启动、绕障到达与全程不穿透、背景山体边界及绘制顺序，1440×960 和 844×390 截图均已检查，运行时无页面错误。窄屏检查不等于完整触屏真机验收。

可选浏览器检查：先启动 `npm run serve`，再执行 `npm run test:browser`。需要外部可用的 Playwright 与浏览器；可通过 `PLAYWRIGHT_MODULE` 指定模块路径、`CHROME_EXECUTABLE` 指定浏览器、`GAME_URL` 指定服务地址。该检查不包含在零依赖 `npm test` 中，截图写入系统临时目录。

本机补充压测：六章分别运行至 180 秒或正常结束，无非有限坐标；220 单位纯移动模拟 180 帧，P50 约 1.09ms，P95 约 1.19ms，最慢约 5.61ms。此结果仅代表本次本机纯模拟采样，不代表包含 GPU、DOM、音频的整机帧率，也不是平衡性结论。

### 边界

圆形占地为现有几何的近似，单位间仍是软避让，不保证人群绝对不重叠。完全封闭目标保持等待，不自动拆建筑或修改命令。当前 16 边轮廓可能放弃极窄缝隙；后续需用更多复杂地图和真实输入进一步验收。新寻路会改变接敌与采集时间，需要后续独立平衡验证。

## 第三轮交付：档案完整性与输入恢复（2026-11-14）

- 档案导入显式拒绝不支持的版本和损坏的 profile 包装，失败保留原档案；继续兼容无版本旧档案。
- 导入及读取统一约束胜场不大于总场、败场不大于剩余场，避免零场有胜绩、胜率超过 100% 或胜败合计超过总局数。
- 窗口 blur 或页面隐藏时释放移动键、Shift、边缘滚屏、拖拽与框选，并取消尚未 mouseup 的点击；保留暂停与待建造意图。
- 增加档案完整性、瞬时输入恢复行为测试，纳入统一回归。完整回归及六章三难度 18 组持续模拟通过。
- 本轮环境未安装 Playwright，未运行真实浏览器验收；此前浏览器验证不能替代本轮焦点切换实测。
- 群主本轮授权 Codex 牵头设计与开发、按批自动继续；此前需等待 DeepSeek 定稿的分工以此授权为准。
