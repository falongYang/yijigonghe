# 整体交付路线（2026-11-16）

目标：交付可访问、可完整游玩的《蚁纪·共时》。项目现状仍为 Web MVP，不因职责授权改变完成度。

## 发布门槛

1. 先关闭 R4：重开保留对局、多塔实际完工覆盖、第一章主动策略验证、普通入口至结算重开浏览器验证。Mac 触控板需要真实输入复验。
2. 发布可玩版本：完整回归、六章三难度持续模拟、浏览器无未捕获异常；提交推送后使用同一提交部署，核对线上资源与启动路径。
3. 体验深化：逐章目标与节奏、教学可理解性、资源及战斗反馈、移动与窄屏交互、性能采样；每批提供实测证据。
4. 完整游戏扩展：战局存档恢复与版本校验、章间进度、各章差异与内容、挑战与成就、美术音频一致性。功能须有完整流程验收，不以功能数量代表质量。

## 当前可确认验证

- 重开补丁：沿用 reload 生命周期，将当前蚁种、模式、章节、AI 类型与难度写入已有自动开局参数。
- `bun run-tests.mjs`：所有语法及行为回归通过。
- `bun test-soak.mjs`：六章三难度18组，50,785 ticks，状态不变量通过。被动玩家出现失败属于样本结果，不表示主动玩家可通关。
- 浏览器与多塔、主动策略探针并行验收，结果另记，不提前宣称通过。
