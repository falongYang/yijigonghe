# 战斗与战术体验升级

日期：2026-11-14（Asia/Shanghai）。本轮按“指令可靠 → 战斗可读 → 地图可用 → 动画与地形一致 → 战后反馈”完成一个贯通的体验升级版本。

## 设计依据

参考成熟 RTS 的通用规则，重新适配蚁群题材；没有搬用商业游戏的美术、音频、剧情或代码。

- [官方操作与采集指南](https://www.ageofempires.com/learn-to-play/control-resources-aoe2/)：选择与右键上下文指令、生产建筑集结点、持续可读的资源/人口/时代信息。用于检查既有操作的一致性，以及修复开始页选择没有完整传入开局的问题。
- [官方战场元素指南](https://news.blizzard.com/en-us/article/4546768/game-guide-map-elements)：区分未探索与曾探索区域；敌军动态不应通过地图泄露；据点和可破坏障碍有战略价值。用于本轮探索记忆、敌巢最后目击与全图设计。
- [官方高地与掩护说明](https://classic.battle.net/scc/gs/hc.shtml)：地形应改变战术。保留项目已有高台射程、泥沼/浅滩移速规则，本轮让地貌、坐标和路线更容易查看；未直接照搬该来源的命中概率。

## 实现规则

### 真实普攻时序

- 近战起手 0.16 秒，远程起手 0.20 秒。冷却从起手开始计算，避免叠加一整段额外冷却。
- 近战在接触时检查存活、可锁定和距离。目标提前离开攻击范围则本次攻击落空。
- 移动、停止、驻守、目标切换和眩晕可取消未释放的攻击；已释放弹体继续飞行。
- 远程弹体与模拟共用飞行寿命，命中才扣血并播放命中特效。弹体追踪目标，目标死亡或潜行后不追加伤害。
- 攻击者死亡不会抹去已发射弹体，但不能凭该弹体回血或升级复活。
- 远程增伤按发射时的单位增伤记录，飞行途中增益到期不削掉已发出的一击。范围技能、持续伤害仍按其原有规则执行。
- 修复 `buff.dmg` 原先仅写入、未进入伤害计算的问题，使狂暴与信息素号令兑现描述。
- 警戒塔也使用飞行命中；直接伤害接口保持兼容，命中不再重复生成第二条飞行轨迹。

### 指令与流程修复

- 攻击移动保留原目的地，消灭沿途目标后继续前进；新指令清除旧目的地。
- H 键和详情面板的驻守调用同一模拟命令。驻守的小步调整使用时间步与寻路，不再每帧直接挪动固定距离。
- 眩晕时实际停止移动/攻击，同时继续衰减状态计时和结算已有中毒。
- 开始页的模式、章节、难度选择完整传入开局；此前 `onStart` 只转发了蚁种。
- 修复战报胜者读取字符串结局状态的口径。

### 战术地图与侦察

- L 键或顶部“战术图”打开全图，使用独立高分辨率底图，不把小地图直接放大。
- A–H / 1–6 分区坐标；水域、地貌、资源、建筑、障碍、信息素井、当前镜头位置与选中路线同步显示。
- 点击定位镜头，右键移动，Shift + 右键攻击移动；触屏通过“点击下令”切换操作。暂停期间可以查看和定位，但不能下令。
- 资源/地形/选中路线图层可独立开关。指针经过资源与据点可查看储量/归属/占领进度。
- 47×34 侦察网格约每 0.25 模拟秒刷新：深色未探索、灰色曾探索，敌方单位仍只显示当前可见目标。虚线建筑是最后目击记录，不代表当前位置仍有建筑。
- 重新侦察已被摧毁的建筑位置后清除过时记录。未见过的建筑不产生记忆；敌方蚁后巢保持原有“已知战略目标”规则。
- 全图上视野外资源的储量显示 ?，需要侦察。资源点位置作为公共地图信息保留。
- 全图拥有键盘焦点循环；Esc 关闭并归还焦点，打开期间屏蔽战场快捷键并清除相机平移状态。

### 动画与地形

- 合并几何保留腿根和触角铰点，顶点着色器让三足一组交替摆动、抬足，工作时触角加强探查；不会为每只蚂蚁额外增加六条腿的绘制调用。
- 躯体与深度阴影共享同一套动画参数。铰点随原模型 2.2 倍缩放同步变化，阴影材质随单位回收。
- 步频来自模拟的 gait，停止或眩晕时停止足部迈步。水栖与飞行单位降低足部摆幅。
- 修复单位/建筑固定在世界 y=0 的问题，统一采样 `terrainHeight`；蚂蚁身体按足底高度抬升，受击弹起叠加在站姿之上。
- 建筑选中圈、集结旗、战术标记、建造准星、命令落点、危害区中心和移动扬尘同步贴地。地面拾取改为命中实际地形，减少坡地指向偏差。
- 指令线复用对象池，沿寻路拐点与每 4 地面单位插值贴地，最多 256 顶点，避免直线穿入山坡。
- 弹道起终点跟随地形与空中高度，死亡下沉以当前位置地面为基准。

### 战场纪事与结算

- 全图显示最新十二条关键事件；结算显示本局五个高光，按时间顺序呈现。
- 复制战报加入高光时间、事件及说明。外部文本输出到 HTML 时转义，颜色与时间清洗。
- 生存、采集、占领等胜利使用实际胜因，不再一律声称摧毁敌巢。

## 验证

- `npm test`：23 个 JS 模块语法、导入核对、基础模拟回归、寻路回归、第 14–33 批既有检查，以及本轮新增的 22 项战斗时序和 25 项体验检查。
- `npm run test:soak`：固定随机种子的六章 × 三难度，共十八组模拟，运行至 180 秒或正常结束，检查坐标/生命/计时、在飞弹体、经济非负、资源储量和占领进度。该测试不操作玩家，也不代表胜率平衡结论。
- `npm run test:browser`：真实 Chrome + 软件 WebGL 验证启动/绕障，检查几何含两组足部和两侧触角铰点、单位贴地和阴影动画共享；检查开始页选择传递、H 驻守、L 全图、Esc 关闭、地图事件、目标胜因和结算高光。检查 1440×960、844×390 两种尺寸的地图与 HUD。
- 本机补充 220 单位开场战斗模拟 240 帧：纯模拟 P50 约 0.97ms、P95 约 4.77ms、最慢约 11.84ms，结束时 171 单位、19 发在飞弹体。数字不包含渲染、DOM 与音频，不可直接换算完整游戏帧率。

## 实际边界

本轮完成的是这套体验升级版本，不代表整个游戏达到最终商业品质。动画是程序化关节摆动，尚无逐足 IK 或坡面接触解算；视野不包含地形遮挡，侦察阴影目前用于地图而非整个 3D 战场。弹体追踪目标，未引入物理碰撞或弹丸躲避。单位仍使用软避让，未增加多人联机、战局存档或云端账户。

起手、飞行时序以及修复后的增伤会改变接敌和战斗结果，需继续用实际玩家对局校准。服务器发布以逐文件校验结果为准，不能用“脚本退出成功”代替线上核验。
